## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
pnpm build
pnpm start
```

Set `NEXT_PUBLIC_SITE_URL` to the public origin before deploy so canonical URLs, the sitemap, and Open Graph links resolve. Without it, those absolute URLs stay local and the sitemap is empty on purpose.

Deploy this repository on Vercel. Framework preset: Next.js. Install command: `pnpm install`. Build command: `pnpm build`.
